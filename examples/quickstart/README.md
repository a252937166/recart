# Quickstart

```sh
node quickstart.mjs                                   # against https://recart.axiqo.xyz
RECART_BASE_URL=http://127.0.0.1:4060 node quickstart.mjs
```

It creates a sandbox store, opens a recovery for the store's reference order (its 2-in USB-C interface is missing), prints the proposal ($376.92 → $422.28), creates the buyer's review link, sells out the replacement interfaces (proposal v2: `no_supported_bundle`), restocks one (v3: `proposal_ready`), and lists the events and the signed callbacks the hosted inbox verified. Open the printed review link to see the buyer's page.
